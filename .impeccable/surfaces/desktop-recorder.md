# Desktop recorder surface

Mode: Operate

## Direction contract

THESIS: One-screen recorder studio — the record control is the product; setup is secondary; browser opens when done.

OWN-WORLD: Web-aligned zinc + `#625df5` accent; native macOS density; no stacked cards or uppercase section labels.

STORY: Pick screen and mic, hit record, window hides; stop from tray; recording opens in browser. Errors stay visible without a share-link panel.

FIRST VIEWPORT: Compact top bar (mark, title, live status pill, refresh). Centered 88px record orb with one line of state copy beneath. Screen rows and mic select in a flat setup band. Advanced log/diagnostics collapsed at the bottom.

FORM: Studio console — assigned from Loom-native recorder + web gallery tokens.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
